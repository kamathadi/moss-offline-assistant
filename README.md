# Moss

Moss is a Windows desktop offline AI assistant, with a small companion website.

## Build

Requires Windows and the .NET 8 SDK with the Windows desktop workload. Open `Moss.csproj` in Visual Studio or build it with `dotnet build` on a configured Windows machine.

Build outputs, downloaded model files, local work, and deployment metadata are excluded from this repository. The public repository contains the application source and website assets.
